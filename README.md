# ASCII テトリス（最終課題：機能拡張版）

Pythonの標準ライブラリ（`random`, `time`, `__future__`）と `terminal_io` を用いたターミナル上で動作するASCIIテトリスです。
ベースのサンプルプログラム（回転、接触、固定、横一列の消去、ゲームオーバー実装済み）に対して、プレイ性と視認性を向上させるための **4つの新機能** を追加しました。

---

## 実行方法

ターミナルでプログラムのディレクトリに移動し、以下のコマンドで起動します。

```bash
py tetris.py
```
（環境によっては `python tetris.py` または `python3 tetris.py`）

---

## 操作方法

| キー | 動作 |
| :--- | :--- |
| `A` / `←` | 左へ移動 |
| `D` / `→` | 右へ移動 |
| `W` / `↑` | 時計回りに回転（壁際では1～2マス横へ補正する簡易ウォールキック対応） |
| `S` / `↓` | 落下を加速（ソフトドロップ） |
| `Space` | 一気に落下して固定（ハードドロップ） |
| **`C`** | **現在のブロックをホールド（一時保存・交換）** ※追加機能 |
| `P` | 一時停止 / 再開 |
| `R` | ゲームを最初からやり直す |
| `Q` | ゲーム終了 |

---

## 追加・改良した機能（4点）

### 1. ホールド機能（`hold_piece`）
- **概要:** `C` キーを押すことで、現在操作中のブロックを `HOLD` 枠に一時保管し、後で必要なタイミングに入れ替えて使用できるようにしました。
- **実装内容:**
  - `Tetris` クラスに `hold_kind`（保管中のブロック種類）と `can_hold`（連続使用防止フラグ）を追加しました。
  - `hold_piece()` メソッドを新規実装し、1ターンに1回のみブロックの保管・交換ができるように制御しています。
  - 画面上部のステータスバーに現在の `HOLD` 状態を表示します（未保管時は `-` を表示）。

### 2. ゴーストピース機能（`get_ghost_y`）
- **概要:** 操作中のブロックがそのまま真下に落ちた場合の着地予測位置を `::` で表示し、ハードドロップ時の操作ミスを防げるようにしました。
- **実装内容:**
  - `get_ghost_y()` メソッドを新規実装し、現在の `y` 座標から `can_place()` が `False` になる直前の `y` 座標を探索します。
  - `render()` メソッド内で着地予測位置に `'G'` を配置し、`::` として描画しています（実体ブロックと重なる部分は実体ブロック `[]` を優先描画）。

### 3. 次ブロックの視覚的プレビュー表示（`format_mini_piece`）
- **概要:** 次のブロックを実際のブロック形状（`[]`）で視覚的に確認できるようにしました。
- **実装内容:**
  - `format_mini_piece(kind)` メソッドを新規実装し、`SHAPES` の座標データをもとに 4×2 のミニグリッド上でブロックの形を生成します。
  - 操作説明の下部に `Next Block:` セクションを追加し、次に出現するブロックの形を分かりやすく表示しています。

### 4. レベルアップ・スピード変化・目標スコア表示機能（`check_level_up`）
- **概要:** 一定スコア（`LEVEL_STEP_SCORE = 500`）を獲得するごとにレベルが上がり、落下速度の上昇と獲得スコア倍率が増加するゲーム進行システムを追加しました。
- **実装内容:**
  - `check_level_up()` メソッドを新規実装し、現在のスコアが `next_level_score` に達するとレベルが上昇し、`★ LEVEL UP! (Speed Up!) ★` の通知メッセージを画面下部に表示します。
  - `fall_interval` プロパティをレベル連動に変更し、レベルが上がるごとにブロックの落下速度が速くなるように調整しました。
  - 画面上部に現在のレベル（`LV`）を表示し、画面下部に次のレベルアップまでに必要な残りスコア（`Next Level (LV X): あと ○○ pts`）をリアルタイム表示します。
